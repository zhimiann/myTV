# LibreTV 自动采集点播源

> 本分支由 GitHub Actions 自动生成，每天更新一次（北京时间 08:00），请勿手动修改。

## 订阅地址

在 LibreTV：设置 → 源管理 → 数据源订阅，粘贴：

```
https://raw.githubusercontent.com/zhimiann/myTV/source-list/source-list.latest.json
```

## 文件说明

- `source-list.latest.json` — 探活通过、按耗时升序的 top-N 活源
- `source-list.latest.report.json` — 完整探活报告（每个源的耗时、失败原因）
